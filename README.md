## 😵 先说个扎心的事实

「三庭五眼」这四个字，你背得比课文还熟。

但真到动笔——

- 正面勉强能看，**一侧脸就塌** 🌀
- 想画仰视、俯视、回头 45°，五官位置全靠猜
- 收藏夹里存了几百张参考图，**偏偏没有你要的那个角度**
- 打开 Blender / CSP，模型是有了，可调个头型比画画还费劲

问题从来不是你不够努力，而是：**你脑子里有一套平面公式，手上却没有一个立体模型。**

> ✏️ 三庭五眼教你「在正面上怎么分」，Loomis 教你「在球体上怎么切」。
> 而绝大多数人，卡在这两套方法之间的那一步。

这，就是捏脸大师 Pro 存在的理由。

## 🧠 它到底是个什么东西

一句话：**把「三庭五眼 + Loomis 人头」变成可以实时变形、360° 旋转、一键导出的 3D 模型。**

不是贴图，不是预制模型，不是静态图片——所有的结构线都是**参数驱动的程序化几何**。你拧动任何一个参数，线框当场跟着变形。

## 🚀 三个我最有底气的地方

### ① 三种模式，覆盖「从入门到进阶」的完整路径

| 模式 | 解决的问题 | 适合谁 |
|---|---|---|
| 🧊 **方体（三庭五眼框架）** | 先把比例吃透，别急着画脸 | 纯新手 |
| 💀 **人头（Loomis 线框模型）** | 把平面比例套进真实颅骨结构 | 有基础、要练透视 |
| 🔀 **分屏对比（左方体 · 右人头）** | 同步旋转、同步比例，看着「几何体」长成「真头」 | 卡在过渡期的人 |

分屏模式是很多人第一次用就「啊」出来的功能：**两个模型完全同步**，你转左边，右边跟着转；你改比例，两边一起变。

那一刻你会突然明白——原来眉弓为什么要压在那个高度，原来鼻底到下巴的那一段，才是决定脸「长不长」的关键。

### ② 五官位置不是「拖」出来的，是「算」出来的

大部分 3D 工具让你用鼠标拖着摆五官——歪一点、高一点，全凭手感，越调越乱。

这里不一样：**五条水平线（发际线 → 眉弓 → 眼睛 → 鼻底 → 嘴巴）逐条可调、可显隐**，而且**自动约束前后顺序，永远不会互相穿模、不会越线**。

- 📏 每一段间距独立调节，精确到「这块脸长一点 / 短一点」
- 🔒 「锁定总高」一开，圆球高度与下巴高度此消彼长，整体比例不乱
- 🦴 颌骨宽度 / 倾角 / 下颌高度 / 下巴尖 / 下巴宽 —— 圆脸、方脸、瓜子脸，捏出来

【插入图 03｜参数面板特写：五条水平线 + 颌骨参数】

### ③ 四种年龄模板，一键换脸

从零调参数是进阶玩法，赶稿时你只需要「快」：

- 👶 **儿童**：圆颅 · 短脸 · 小圆下巴
- 🧒 **少年**：轮廓柔和 · 脸略长
- 🧑 **成年**：标准比例 · 清晰颌线
- 🧔 **粗犷**：宽方颌 · 长脸 · 强下巴

点一下就切，切完还能继续微调。**先套模板再改**，比从零开始快十倍。

## 👥 它适合谁？

- ✅ **刚学画画的新手**：先把比例吃透，比临摹一百张脸有用
- ✅ **画同人 / 立绘的画师**：需要 45°、仰视、俯视的准确头部参考
- ✅ **自学党 / 美术生**：想验证「我理解的透视，到底对不对」
- ✅ **做角色设计的**：快速试不同年龄、脸型、骨相
- ✅ **需要临摹素材的老师**：一键导出整版多角度图，直接发给学生

**不适合谁？** 想一键生成成品角色模型的人，请右转 VRoid 类软件——这不是它的定位，它也不打算抢这个活。🙂
